# Privacy Policy for No Short Skills

Effective date: October 18, 2026

This package contains instruction-based skills. It does not bundle a local usage collector, MCP server, telemetry or a developer-hosted backend.

Skills can guide an agent to read files or work with connected services selected by the user. The agent host and those services process the resulting data under their own terms, privacy policies and account settings. A work report uses the evidence sources you choose; Jira, GitHub and Slack are not all required. Review skill instructions and connection permissions before use.

If you open a GitHub issue, information you include is processed by GitHub and can be public. Do not include secrets or private report data. Questions: https://github.com/longlonglong173/no-short-skills/issues.

No Short Usage has its own [privacy policy](https://github.com/longlonglong173/no-short/blob/main/PRIVACY.md).
